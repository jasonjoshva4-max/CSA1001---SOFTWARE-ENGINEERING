# EXP-8: Requirements Prioritization for an Online Learning Platform using MoSCoW and Kano Model

**Course:** CSA1001 – Software Engineering | **Experiment No.:** 8  
**System Under Study:** Online Learning Platform (EdTech System)

## 1. AIM
To gather, analyze, and prioritize requirements for an **Online Learning Platform** using **MoSCoW** and **Kano Model** to balance core educational delivery with user delight.

## 2. REQUIREMENTS CLASSIFICATION TABLE
| ID | Requirement | MoSCoW | Kano | Justification |
|---|---|---|---|---|
| **FR-01** | Student/Instructor Auth | Must Have | Basic | Core entry point. |
| **FR-02** | HD Video Playback | Must Have | Basic | Primary content delivery. |
| **FR-03** | Course Search & Filters | Must Have | Basic | Discovery baseline. |
| **FR-04** | Payment Gateway | Must Have | Basic | Commercial monetization. |
| **FR-05** | Progress Tracking (%) | Should Have | Performance | Encourages completion. |
| **FR-06** | Interactive Quizzes & Auto-grading | Should Have | Performance | Assessment essential. |
| **FR-07** | PDF Course Certificate | Should Have | Performance | Learner reward. |
| **FR-08** | Discussion Q&A Forum | Should Have | Performance | Community support. |
| **FR-09** | AI Chatbot Tutor 24/7 | Could Have | Attractive | Instant doubt resolution delight. |
| **FR-10** | Offline Video Download | Could Have | Attractive | Low-connectivity delight. |
| **FR-11** | Interactive Code Sandbox | Could Have | Attractive | Hands-on coding delight. |
| **FR-12** | Gamified Badges | Could Have | Attractive | Engagement booster. |
| **FR-13** | VR Lab Simulations | Won't Have | Indifferent | Out of current scope/budget. |
| **FR-14** | Mandatory Social Media Post | Won't Have | Reverse | Intrusive to user privacy. |

## 3. RELEASE ROADMAP
- **Release 1 (MVP - Baseline):** Auth, Video Player, Course Search, Payment Gateway (Must Have / Basic).
- **Release 2 (Enhancements):** Progress Tracking, Quizzes, Certificates, Q&A Forum (Should Have / Performance).
- **Release 3 (Next-Gen):** AI Tutor, Offline Downloads, Code Sandbox (Could Have / Attractive).

## 4. CONCLUSION
Dual prioritization provides a clear roadmap from baseline MVP to innovative market differentiator.
