# Task 3: ShopVista Mobile Stakeholder Review Prototype

This task contains a single self-contained HTML prototype for comparing two e-commerce mobile UI directions side by side.

## Included
- **Variant A: Minimalist & Direct**
- **Variant B: Rich & Discovery-Focused**
- **Interactive stakeholder feedback form**
- **Live decisions summary table**

## How to run
1. Open `index.html` in a modern browser.
2. Review the two mobile mockups side by side.
3. Submit stakeholder feedback using the form.
4. Confirm that each response is added to the live summary table.
