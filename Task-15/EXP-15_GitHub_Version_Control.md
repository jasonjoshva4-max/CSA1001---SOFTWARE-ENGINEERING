# EXP-15: Comprehensive Guide to Version Control using Git and GitHub

**Course:** CSA1001 – Software Engineering | **Experiment No.:** 15  
**Tools Used:** Git CLI, GitHub Cloud

## 1. AIM
To master core **Git and GitHub operations** including initialization, staging, committing, history inspection, branch management, remote tracking, pushing, pulling, and tagging.

## 2. EXAM QUICK REFERENCE CHEAT SHEET
- `git init`: Initialize new repository.
- `git status`: View working tree and staging state.
- `git add <file>`: Move changes to Staging Area.
- `git commit -m "msg"`: Save snapshot to Local Repository.
- `git log --oneline`: View commit history summary.
- `git branch -M main`: Set default branch name.
- `git remote add origin <url>`: Connect local repo to remote GitHub.
- `git push -u origin main`: Upload commits to GitHub.
- `git checkout -b <branch>`: Create and switch to new branch.
- `git merge <branch>`: Merge branch into current branch.
- `git tag -a v1.0.0 -m "release"`: Create release tag.
