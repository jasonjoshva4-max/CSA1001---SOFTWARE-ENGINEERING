# EXP-1: Kanban Board to Visualize Tasks

**Course:** CSA1001 – Software Engineering  
**Experiment:** 1  
**Tool Used:** Trello

## Aim
To create a Kanban board to visualize software-development tasks and simulate the workflow using To Do, In Progress, and Done columns.

## Board Columns
- **To Do** – Tasks that are yet to be started.
- **Doing (In Progress)** – Tasks currently being worked on.
- **Done** – Tasks that have been completed.

## Tasks Used
1. Collect Requirements
2. Design Database
3. Create Login Module
4. Develop Patient Registration
5. Develop Appointment Module

## Workflow Demonstration

| To Do | Doing / In Progress | Done |
|---|---|---|
| Create Login Module | Design Database | Collect Requirements |
| Develop Patient Registration | | |
| Develop Appointment Module | | |

The tasks were moved between the columns to simulate the workflow:

**To Do → In Progress → Done**

## Result
A Kanban board was successfully created in Trello with three workflow columns and five sample software-development tasks. The movement of tasks across the columns demonstrated the Kanban workflow.
